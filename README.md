# Larah Melyssa · Nutricionista

Site de portfólio, blog e agendamento de consultas (Calendly).

Site estático: um único `index.html`, sem etapa de build e sem dependências.

## Rodar localmente

```bash
npx serve .
```

## Publicação

GitHub → Vercel → site. Cada push na branch `main` publica uma nova versão.

Na Vercel: **Add New → Project**, importar o repositório e manter as opções padrão
(Framework Preset: *Other*, sem comando de build, diretório de saída vazio).
